# 07. 其他學習資源與進階主題

本頁面收錄其他類型的學習資源，並不局限於政大通的業務或是資工領域，說不定你可以在這裡找到意料之外的收穫。

---

## Linux
- [成大資工Linux教學](https://wiki.csie.ncku.edu.tw/linux/schedule)
- [鳥哥的Linux私房菜](https://linux.vbird.org/)

提供linux及伺服器架設詳盡且手把手的文字教學，來自2015的資料略顯古老，但要拿去傳統藝術中心卻嫌早，2026年依然有一戰之力。

## CS
- [OSSU Computer Science](https://github.com/ossu/computer-science) 

幾乎涵蓋大學四年CS領域開放式課程，不管你是誰，學完就可以考資工所了。

- [藍不過海啊](https://space.bilibili.com/401399175) 

Bilibili上主要教授資料結構的頻道，透過動畫直觀展示資料結構的操作。

## 大學生活
- [上海交大生存手冊](https://github.com/SurviveSJTU/SurviveSJTUManual/blob/master/SUMMARY.md)

儘管學校國情不同，但還是有不少共通的地方值得看看，作者文筆生動有趣，拿來打發時間也不錯。

## 資訊安全
- [portswigger](https://portswigger.net/web-security/)

免費高品質的網路安全學習網站，先用閱讀的方式建立概念，然後到Lab去實戰演練，主打現學現賣。

## 玩具
- [bongo cat](https://github.com/ayangweb/BongoCat)

實時追蹤你的鍵盤滑鼠操作的貓貓替身。
